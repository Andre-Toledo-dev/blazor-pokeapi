# Blazor PokeAPI

Aplicação web desenvolvida em C# utilizando Blazor WebAssembly para consultar informações de Pokémon por meio da PokéAPI.

## Funcionalidades

- Pesquisa de Pokémon pelo nome.
- Consumo da API REST PokéAPI.
- Exibição da imagem do Pokémon.
- Exibição do ID, nome, altura e peso.
- Tratamento de erros para Pokémon não encontrados.

## Tecnologias utilizadas

- C#
- .NET 10
- Blazor WebAssembly
- HTML
- PokéAPI

## API utilizada

https://pokeapi.co/api/v2/pokemon/ditto

## Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Execute `dotnet restore`.
4. Execute `dotnet run`.
5. Acesse o endereço local informado no terminal e abra a página `/pokemon`.
